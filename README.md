# Snake Game — Team 11

Console-based Snake Game implemented in C.

## Prerequisites

- Windows
- GCC (MSYS2 UCRT64)
- VS Code

## Compile

```bash
mingw32-make
```

## Run

```bash
.\snake.exe
```

## Controls

- Arrow keys or WASD: Move / navigate
- Enter: Select
- Escape: Return to menu during gameplay
- X: Exit
